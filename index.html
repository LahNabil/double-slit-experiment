Pour enregistrer

  1. Ouvre la page en plein écran (F11).
  2. Lance l'enregistreur : Win + Alt + R sur Windows, Cmd + Maj + 5 sur Mac, ou OBS.
  3. Clique Lancer le scénario, attends la fin.
  4. Recadre sur le carré et coupe le début.
